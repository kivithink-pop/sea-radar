# 🌏 Sea Radar — 东南亚前沿信息雷达

> 持续采集 · 甄选筛选 · 本地存档 · 对外发布

Sea Radar 是一个面向 **东南亚（Southeast Asia, SEA）** 的开源信息聚合项目。  
目标是建立一个**长期可维护**的本地历史数据库，并基于此对外发布有价值的前沿信息。

---

## 🎯 项目目标

- **持续关注** 东南亚地区的政治、经济、科技、社会、文化等前沿动态
- **甄选筛选** 有价值、可信度高的信息源
- **本地存档** 所有采集到的信息，建立可检索的历史数据库
- **对外发布** 通过一个独立的发布站点（后续建设），向公众展示经过整理的内容

---

## ✨ 核心特性

- 📡 **多源采集** — RSS、API、网页抓取等多种信息源
- 🧠 **智能甄选** — 关键词过滤、来源可信度评估、去重
- 🗄️ **本地存档** — 结构化存储，支持时间序列查询
- 🌐 **对外发布** — 配套网站，将甄选后的信息以友好形式呈现
- 👥 **多人协作** — 与 HU 共同维护，欢迎社区贡献

---

## 🏗️ 项目结构（规划中）

```
sea-radar/
├── data/                # 本地历史数据库（JSON/SQLite）
│   ├── raw/            # 原始采集数据
│   ├── processed/      # 甄选处理后的数据
│   └── archive/        # 归档数据
├── sources/            # 信息源配置
│   ├── rss/            # RSS 订阅源
│   ├── api/            # API 数据源
│   └── websites/       # 网页抓取源
├── scripts/            # 采集、处理脚本
├── docs/               # 项目文档
├── website/            # 对外发布站点（后续建设）
└── README.md
```
